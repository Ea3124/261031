# 최초 설치 도구 검증

이 기록은 setup.sh와 로컬 훅 연결의 검증이며 실제 과제 앱의 기능 통과를 뜻하지 않는다. 모든 결함은 별도 임시 복사본에만 넣었다.

- baseline.log: 전체 검사 33개 통과
- mutations/: 설치 핵심 규칙 7개를 의미상 깨뜨린 patch, 문법 검사, 실제 실패와 같은 검사로 복구한 성공 로그
- result.json: 참고 자료 식별자, 명령, 종료 코드, 검증 전후 원본 코드 해시

복사 충돌 검사는 실행 가능한 외부 스크립트로 시험해 실행 권한 검사에 의한 우연한 실패와 구분했다. 기존 훅 충돌 검사는 종료 코드뿐 아니라 복사 전 작업 파일이 그대로인지 확인한다. 결함주입 기록은 최종 작업 코드에 적용하지 않았다.
