# 인계

현재 파일은 새 과제를 위한 틀이다. 세션 전환·중단·완료 때 마지막 검증 전에 실제 상태를 작성한다. 작성 시점의 사실과 최종 검증에서 확인할 사항을 구분한다.

- 현재 목표와 마지막 요구 변경:
- 브랜치·확인한 직전 SHA·미커밋 변경:
- 주요 코드 구조·자료형·저장 위치:
- 정확한 시작·초기화·검증 명령:
- 증거: .evidence/latest가 가리키는 result와 실제 산출물을 확인한다.
- 실제 통과 범위·검증 전 확인할 사항:
- 실패·미실행·수동 확인·남은 위험:
- 다음에 수행할 명령 또는 수정 한 가지:

이전 세션의 요약만 믿지 말고 Git 상태·현재 앱·초기 상태·환경을 확인하고 같은 절차로 실제 검증한다. 아직 검증되지 않은 변경은 그대로 명시한다. 최종 커밋 SHA를 그 커밋 자신에 포함시키는 순환은 만들지 않는다.

이 문서를 작성한 뒤 ./scripts/check → 코드·증거 함께 스테이징 → 커밋 순서로 끝낸다. 실제 최종 결과와 SHA는 완료 응답에 남긴다. 새 run ID를 문서에 계속 덮어써서 재검증을 반복하지 않는다. 검증 불가·시간 종료이면 미검증·미커밋 상태를 그대로 인계한다.
