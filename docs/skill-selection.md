# pstack 전체 스킬 검토와 선별

이 표는 backnotprop/pstack의 고정 SHA 25abb38559ddbabec563646224d09eff9a250eca를 검토한 선별 이력이다. 루트 스킬 58개와 Benny 3개, 총 61개를 전문 읽었고 연결 참조 25개도 검토했다. RULE.md 원본은 변경하지 않았다.

## 편집 기준

- 현실적인 시작·설계·구현·기능 기억·고정 방법 검증·핵심별 결함주입·수정·증거 포함 커밋·인계에 필요한 판단만 추출했다.
- 원본 전체 대신 7개의 한국어 스킬로 편집했다. 전부 매번 실행하는 절차가 아니다.
- 모델 선택·강제 위임·PR/push·UI 자동조작·개인 설정·외부 메시지·범용 상태 관리는 실행 의존성에서 제외했다.
- 모호한 기대 동작을 알아서 정하거나 예산 없이 무한 반복하는 규칙은 채택하지 않았다.
- 핵심 증거를 Git에 남긴다. 원본 TSV 6열과 교차모델 리뷰는 강제하지 않는다.
- vendor 원본 디렉터리는 제거했다. 원문은 아래의 고정 upstream 링크로 확인하며, 편집한 7개 스킬과 허가문·과거 검토 해시 기록은 보존한다.

## 독립 사용과 라이선스

현재 스킬은 01–07 번호로 정리되어 있고 원본 실행기와 모델 설정 없이 읽을 수 있다. 시작 단계의 업무 질문 정리 방식은 이후 cofa-ready-kit를 참고해 추가 개편했으며, 이 표의 pstack 선별 이력과 구분한다. 출처 링크는 원문 비교용이며 실행 의존성이 아니다. 다른 프로젝트에 복사할 때 .agents/skills/LICENSE.pstack과 .agents/skills/LICENSE.cofa-ready-kit를 함께 보존한다. .evidence/curation/skills.json의 예전 vendor 경로·해시는 삭제 전 원본을 식별하는 과거 기록이며 현재 로컬 경로가 아니다.
