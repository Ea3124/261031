# 작업 의도

U001은 로컬 JSON 장부를 Python CLI로 만든다. 경로 인자를 받고 입금·출금·조회 세 기능을 제공한다. 요구사항의 r1 입금 100, r2 출금 30, 동일 r2 반복 후에도 70, r2 내용 충돌 거절, 새 ID의 71 출금 거절, 새 프로세스 조회 70을 독립 기대값으로 검사한다. 0·음수·문자열은 실패하며 파일 바이트가 보존되어야 한다. 성공한 요청만 ID를 소비하며 잔액은 음수가 되지 않는다.

첫 단위는 25분·3회로 고정한다. 다음 단위는 정상 커밋 뒤 의도적인 중복 반영 회귀를 넣고 실제 커밋 차단과 같은 단위 복구를 확인한다. 기능 맵의 참조 오류, STALE, 정리 후 증거 보존도 확인한다. 검사를 삭제하거나 예산을 초기화하지 않는다.

범위는 단독 프로세스가 순차 호출하는 CLI이며 네트워크·UI·동시 쓰기·인증·다중 통화·성능 보장은 없다. 외부 AI/전송/push/화면 자동조작을 호출하지 않는다. 본 세션은 소유자가 명시 요청한 gpt-6-astra 준비 평가로, RULE의 실전 모델 허가로 해석하지 않는다. 후속 서술형 답변은 범위 밖이다.

제출물은 app/ledger.py, verification/, 앱별 verify-app과 최소 세 맵, work 기록, .kit 실제 증거다. 실행은 프로젝트 루트에서 `python3 app/ledger.py --file DATA deposit r1 100`, 검증은 `python3 kit.py check`다. JSON 표준출력과 종료 코드, 파일의 바이트·내용·남은 파일을 관찰한다. 정상→회귀 차단→원인 복구 커밋과 최종 인계가 완료 조건이다.
