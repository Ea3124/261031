# CSV 주문 집계 의도
합성 주문 CSV의 확정 주문만 집계하는 로컬 CLI를 만든다. 입력 컬럼은 order_id, amount, status이며 음수 아닌 정수 금액과 confirmed/cancelled 상태만 허용한다. 동일 ID와 동일 값은 한 번만 집계하고 충돌은 전체 실패한다. 오류가 있으면 기존 출력 바이트를 보존한다.

요구사항의 독립 기대값: a=100 두 번, b=40 cancelled, c=25 confirmed를 입력하면 확정 건수 2, 합계 125다. 새 프로세스 반복 실행은 같은 바이트여야 한다. 음수·문자 금액·미지 상태·필수 컬럼 누락·충돌·부분 출력 없음까지 검사한다.

빈 Git 프로젝트에 고정 SHA의 키트를 설치했다. 최초 doctor는 미설정 실패였고 HEAD와 증거가 없었다. 제출물은 app/orders.py, verification/, 앱 검증 스킬과 3개 기능 맵, work/ 문서 및 .kit 증거다. 실전 외부 AI·전송·push·화면자동조작은 사용하지 않는다. 이 준비평가의 Astra만 사용자가 명시 승인했다. 웹 화면은 없고 실제 CLI와 파일만 검증한다.

정상 커밋 뒤 중복 집계 회귀를 도입하여 훅 차단과 HEAD 불변을 관찰하고 같은 단위에서 수정한다. 깨진 맵과 STALE을 재현하고 복구하며 정리 후 증거가 남아야 완료다. 임의 제한 초기화·검사 완화는 하지 않는다. 성능, 전원 장애 내구성, 동시 쓰기 순서, 형식 증명은 범위 밖이다.
