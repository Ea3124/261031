# 작업 의도

합성 HTTP 재고 예약 서비스를 빈 Git 프로젝트에 설치한 키트로 구현한다. Python 표준 라이브러리만 사용한다. 초기 재고는 2이고 조회·예약·취소를 제공한다. 서버는 0.0.0.0의 OS 할당 포트를 출력한다. 검사기는 직접 시작한 인스턴스의 포트로만 로컬 HTTP 요청을 보낸다.

입력 r1/수량1은 재고1과 예약 ID를 반환하고, 반복은 같은 ID/재고1이다. 같은 r1/수량2는 오류다. r2/수량1 후 재고0, r3 예약은 거절한다. r1 취소와 반복 취소 모두 재고1이다. 잘못된 입력과 없는 예약 취소는 상태를 바꾸지 않는다. 모든 관측 재고는 0..2다.

범위는 메모리 상태의 JSON HTTP 서비스와 독립된 정적·비즈니스·실행 검사다. 화면, 영속 데이터베이스, 인증, 배포, 성능 보장은 범위 밖이다. 외부 AI 호출·push·전송·화면 자동조작은 수행하지 않는다. 이번 평가는 사용자가 허용한 준비용 Astra 평가이며 실전 모델 허가가 아니다. 실전 권장 모델은 RULE을 따르고 후속 서술형에서는 답변 지원을 종료한다.

완료 조건은 정상 로컬 커밋, 실제 중복취소 회귀로 훅 실패와 HEAD 불변, 같은 단위에서 원인 수정 후 성공 커밋, 잘못된 맵 참조 탐지·복구, STALE 탐지·복구, 서버 종료와 실패 증거 보존이다. U001은 초기 구현에 25분/5회, 후속 회귀 단위는 시작 시 별도로 고정한다. 횟수·시간을 실패 뒤 초기화하지 않는다. 원본 키트 실행기와 공통 문서는 수정하지 않는다.
