# 공통 실행기 통합 검증

- 대상: 첫 공개 버전 c1045e32308fd292a01696406973e5912a442a9c의 실행기.
- 명령: PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
- 루트 직접 실행 결과: 16개 통과, 16.482초.
- 모두 실제 임시 Git 프로젝트와 subprocess를 사용한다.

## 확인 범위

설치 시 기존 README·AGENTS·사용자 hook 보존, 설치 충돌의 사전 탐지, 재설치 멱등성, 원본 helper 실행권한 보존, 미설정 앱의 실패, 실제 커밋 차단과 수정 후 커밋 성공, 부분 stage·미추적 변경 차단, 소스·문서 변경에 따른 STALE, 검사 중 소스 변경 탐지, 기능 맵의 읽기 전용 검사와 runtime 연결, 외부 소스 링크 거절, cleanup 실패, 개별·전체·작업단위 시간 제한, 자식 프로세스 그룹 종료, 재시도 한도·같은 단위 초기화 거절, 최소 환경 상속, 비밀 값 마스킹과 기본 패턴 차단.

## 발견 후 수정

설치기가 bytes만 복사하면 원본 log.sh 등의 실행권한이 사라졌다. 원본 권한의 일반 비트를 보존하도록 수정하고 실제 설치·재설치에서 0755가 유지되는 회귀 검사를 추가했다.

이 결과는 공통 실행기의 검증이며 임의의 미래 과제 앱이 정확하다는 보장이 아니다. 별도 Astra 3개 시나리오의 실제 실행 기록은 해당 평가 보고서로 확인한다.

## 보완 후 최종 검사

예약 변수 오류에 이름을 표시하는 회귀 검사를 추가했고 총 17개가 통과했다(17.223초). 실제 전체 출력은 kit-tests.txt에 보존한다. 최종 실행기 SHA-256은 04a2f86b411305b1748f72c41443ede94195c1b8f96bd6448f0d572160bcabc2다.
